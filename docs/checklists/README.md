# 📋 Checklists de Features Incompletas

Pasta para rastrear features que ainda NÃO estão completas.
Quando uma checklist for 100% concluída, mover o arquivo para
`docs/checklists/done/` e commitar.

| Checklist | Feature | Status |
|-----------|---------|--------|
| [pdf.md](./pdf.md) | Geração de ficha em PDF | ✅ MVP funcional — refinamentos pendentes |
| [rolagens.md](./rolagens.md) | Sistema de rolagens de dados | ❌ Não iniciada |
| [racas-e2e.md](./racas-e2e.md) | Validação E2E das raças restantes | 🟡 Parcial (14/17) |
| [historico-nivel.md](./historico-nivel.md) | Histórico da ficha / level-up com memória | 🚧 Em andamento |

## Como usar
- Ao iniciar uma feature, abra a checklist correspondente
- Marque itens com `[x]` conforme concluir
- Itas descobertos no caminho = novas linhas na checklist
